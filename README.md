# -
Разработала аналитическую витрину на базе многотабличной реляционной БД маркетплейса. Витрина консолидирует поведенческие и транзакционные метрики клиентов топ-3 регионов и служит feature-слоем для ML-моделей (сегментация, churn prediction, программы лояльности). В рамках проекта: аудит качества исходных данных, построение многоуровневого SQL-запроса с агрегацией и оконными функциями, проведение ad hoc аналитических исследований с формулировкой бизнес-выводов.

Разработала решение влияния характеристик игроков и их игровых персонажей на покупку внутриигровой валюты, а также чтобы оценить активность игроков при совершении внутриигровых покупок для gamedev с помощью SQL.

Разработала код в Python для автоматизированного решения оптимизации публикации контента путём интеграции нескольких систем через API и n8n с применением AI-assisted подхода, что повысило масштабируемость процесса и обеспечило возможность автономного ведения социальных сетей. Технический стек: Python (requests, Google APIs, OAuth 2.0), REST API, автоматизация процессов, LLM-интеграция.
